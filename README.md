# iCloud Drive for Windows

iCloud Drive desktop app for Windows. Loads [https://www.icloud.com/iclouddrive](https://www.icloud.com/iclouddrive) in a native **Tauri / WebView2** shell.

## Development

Requires Rust (MSVC), WebView2, and Bun. Sibling crates:

- `Projects/tauri-tray-base`
- `Projects/tauri-icloud-base`

```bash
bun install
bun run icon
bun run dev
```
